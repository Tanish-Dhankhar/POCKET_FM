## Slide 8 — How Ray generates audio differently

**Time: 5:20–6:15 (55 seconds)**

### On-slide copy

## Ray produces scenes—not stitched speech

**1 · DIRECT**
Approved script + episode emotion + character voice bible

**2 · GENERATE ONCE**
One immutable TTS take per spoken line

**3 · BUILD THE PERFORMANCE**
Pause · Pace · Gain · Overlap · Interruption · Edge trimming

**4 · BUILD THE WORLD**
Ambience · Music rises · SFX · Fades · Stereo placement

**5 · PROTECT THE DIALOGUE**
Speech-aware music ducking · Cue retiming · Peak-safe master

**6 · REMIX FAST**
Reuse the original voices; change the direction without another TTS run

### Speaker script

“A typical pipeline sends text to TTS and joins the clips. Ray first combines the approved script with the episode’s emotional goal and each character’s voice identity. It generates every line once and preserves that WAV as an immutable source take. The Audio Director then builds a real performance timeline: variable pauses, pace, gain, true voiced overlap, and interruption. It adds ambience, score, and effects, ducks music only when speech is active, retimes cues after dialogue edits, and creates a peak-safe master. Most importantly, the creator can remix the scene repeatedly while reusing the exact voices.”

Use a left-to-right audio production pipeline. Contrast a tiny **Text → TTS → File** path above it with Ray’s six-stage path.

## Slide 9 — Architecture

**Time: 6:15–7:05 (50 seconds)**

### On-slide copy

## A stateful agent on top of a deterministic production system

**CREATOR STUDIO**
React · Ideaboard · Episode editor · Playback · Audio Director

↓

**API + ORCHESTRATION**
FastAPI · Background jobs · LangGraph · Human approval gates

↓

**AI SPECIALISTS**
OpenAI structured reasoning · Gemini transcription and multi-voice TTS

↓

**DETERMINISTIC AUDIO ENGINE**
Timeline assembly · Overlap · Ducking · Ambience · Mix · Master

↕

**DURABLE SERIES MEMORY**
Atomic JSON artifacts · Character files · Episode folders · Immutable WAV takes · TTS cache

### Speaker script

“React provides the creator-facing studio. FastAPI exposes the workflow and runs long production tasks as background jobs. LangGraph coordinates the stateful agent and human review gates. Structured OpenAI calls handle the story and directing decisions, while Gemini handles transcription and multi-voice TTS. Those model outputs never manipulate audio directly. A deterministic engine validates the plan and performs timeline assembly, overlap, ambience, ducking, mixing, and mastering. Every artifact is then written to durable series storage, which is what gives Ray continuity, restart recovery, selective regeneration, and inspectability.”

### Visual direction

Use a four-layer vertical architecture with **Durable Series Memory** running beside and connecting every layer.
